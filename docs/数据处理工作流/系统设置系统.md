# 系统设置系统

## 系统概述

系统设置系统是erArk游戏中负责管理用户界面设置、游戏难度调整、基础功能开关等配置项的核心系统。该系统通过CSV数据驱动，提供统一的设置界面，支持运行时动态调整，并具备存档持久化功能。

## 核心组件

### 1. 数据定义与配置

#### CSV数据源
- **文件路径**: `data/csv/System_Setting.csv`
- **数据结构**:
  - `cid`: 选项ID (整数)
  - `type`: 选项类型 (`base`基础设置 | `draw`绘制设置 | `difficulty`难度设置 | `birth`生殖方式设置，不在主列表显示)
  - `name`: 选项名称
  - `info`: 选项详细说明
  - `option`: 可选值列表 (用`|`分隔)

#### 配置定义类
- **文件路径**: `Script/Config/config_def.py`
- **类名**: `System_Setting`
- **属性**:
  - `cid`: 选项ID
  - `type`: 选项类型
  - `name`: 选项名称
  - `info`: 选项介绍
  - `option`: 各个选项

#### 游戏配置加载
- **文件路径**: `Script/Config/game_config.py`
- **主要配置字典**:
  - `config_system_setting`: 系统设置数据字典 (设置ID:详细内容)
  - `config_system_setting_option`: 系统设置选项数据字典 (设置ID:选项序号:选项内容)
  - `config_draw_setting`: 绘制设置数据字典
  - `config_draw_setting_option`: 绘制设置选项数据字典
  - `config_difficulty_setting`: 难度设置数据字典
  - `config_difficulty_setting_option`: 难度设置选项数据字典
  - `config_birth_type_setting`: 生殖方式设置数据字典（`type=birth`，键为生育方式编号）
  - `config_birth_type_setting_option`: 生殖方式设置选项数据字典

### 2. 运行时数据结构

#### 系统设置数据容器
- **文件路径**: `Script/Core/game_type.py`
- **类名**: `System_Setting`
- **属性**:
  - `base_setting`: 基础系统设定字典 (`Dict[int, int]`)
  - `draw_setting`: 绘制设定字典 (`Dict[int, int]`)
  - `difficulty_setting`: 难度设定字典 (`Dict[int, int]`)
  - `birth_type_setting`: 生殖方式设定字典 (`Dict[int, int]`，键为生育方式编号，值为0关闭/1开启)
  - `line_before_main_update`: 主界面刷新前的行数
  - `value_draw`: 数值绘制开关
  - `character_text_version`: 角色文本版本字典

#### 缓存数据集成
- **文件路径**: `Script/Core/game_type.py`
- **类名**: `Cache`
- **相关属性**:
  - 总系统设定实例 (`System_Setting`) 不在 `Cache` 上：在 `normal_config.system_setting`，由 `save_load.settings` 存进游戏根目录的 settings.json，不随存档
  - `forbidden_npc_id`: 已禁止干员ID集合

### 3. 用户界面系统

#### 系统设置面板类
- **文件路径**: `Script/UI/Panel/system_setting.py`
- **类名**: `System_Setting_Panel`（主设置面板）、`Game_Basic_Settings_Panel`（语言设置面板）
- **职责**: 负责界面绘制、交互输入循环、子面板导航以及返回时的设置保存，选项行组装、选项循环、数值范围校验、本地配置写入、生殖方式开关与禁止干员切换由 `system_setting_service` 完成
- **核心方法**:
  - `__init__(width)`: 初始化面板，设置绘制宽度与分类映射 `kinds`
  - `draw()`: 主绘制方法，渲染整个设置界面
  - `draw_option(type_name, return_list)`: 绘制指定分类的折叠标题与选项列表
  - `draw_option_row(type_name, row, return_list)`: 根据 `OptionRow` 绘制单条设置项的名称按钮、值或入口按钮及按需附加的禁止干员入口
  - `change_setting_value(type_name, cid, option_len)`: 调用 `system_setting_service.cycle` 并按返回的 `Step` 弹出锁定提示或数字输入框
  - `option_name_info(type_name, cid)`: 显示选项详细信息
  - `change_ban_list()`: 绘制禁止干员选择列表
  - `birth_type_setting_panel_draw()`: 跳转到生殖方式开关子面板
  - `change_birth_type_setting(birth_type)`: 切换单个生殖方式的开关（关闭时确认并清除存量）
  - `confirm_close_birth_type(name, info)`: 关闭生殖方式前的二次确认
  - `chat_ai_setting_panel_draw()`: 跳转到AI设置面板
  - `chat_filter_panel_draw()`: 跳转到指令过滤面板

#### 后端服务
- **文件路径**: `Script/Modules/gameplay_resolution/system_setting_service.py`
- **职责**: 无界面纯逻辑服务，不执行绘制，也不导入 `Script.UI`、`Script.Settle` 或 Tk 模块
- **类型与常量**: `Kind`（设置分类）、`Control`（控件类型）、`Step`（后续动作）、`OptionRow`（选项展示行）、`BanRow`（禁止干员行）、`BirthTypeRow`（生殖方式行）与 `CONTROLS`（特殊控件映射表）
- **公开函数**:
  - `option_rows(kind)`: 返回 `tuple[OptionRow, ...]`，缺失项先补 0（基础与绘制写入 `normal_config.system_setting`，难度只写入本次读取的字典副本）
  - `setting_info(kind, cid)`: 返回整理换行后的选项说明文本
  - `cycle(kind, cid, option_len)`: 推进选项值并按需写回难度表或同步全部角色个人配置第 1 项，返回 `Step`
  - `set_draw_number(cid, number)`: 限制范围并写入 `draw_setting`（11 号存 `number - 1` 限 0~9，其余限 1~99），返回写入值
  - `apply_font_size(size)` / `apply_dpi(dpi)` / `apply_language(lang_code)`: 约束范围、更新 `config_normal` 并写入 `config.local.ini`（前两者返回生效值）
  - `birth_type_rows()` / `birth_type_text(birth_type)` / `birth_type_on(birth_type)`: 读取 `BirthTypeRow` 元组、名称说明与开关状态（缺失键按开启 1 处理）
  - `open_birth_type(birth_type)` / `close_birth_type(birth_type)`: 写入存档生殖方式开关，关闭时调用 `egg_handle.clear_birth_type_data` 清除存量并返回汇报文本
  - `ban_rows()` / `toggle_ban(npc_id)`: 返回跳过玩家 0 的 `BanRow` 元组，切换禁止状态并在禁止在册干员时调用 `roster_lifecycle_service.chara_off_line` 离岛（离岛返回 `True`，其余返回 `False`）

#### 界面布局特点
1. **分类显示**: 按基础、难度、绘制三大类组织设置项（`birth`生殖方式设置不在主列表，由基础设置的入口按钮进入子面板）
2. **折叠展开**: 支持点击标题折叠/展开对应类别
3. **选项切换**: 点击选项值循环切换可选项
4. **信息提示**: 点击选项名显示详细说明
5. **扩展功能**: 特定设置项提供额外功能入口

### 4. 设置值处理机制

#### 难度系数计算
- **文件路径**: `Script/Modules/gameplay_resolution/difficulty_service.py`
- **函数**: `get_difficulty_coefficient(difficulty: int) -> float`
- **系数映射**: `[0.25, 0.5, 0.75, 1.0, 1.25, 2.0, 4.0]`
- **用途**: 将难度等级转换为游戏内修正系数

#### 特殊设置处理
特殊控件由 `system_setting_service.CONTROLS` 统一声明（基础 13 为生殖方式入口，绘制 12 为字体大小，绘制 18 为 DPI 缩放，绘制 14 与 15 为数值输入）。基础设置 12 号由 `system_setting_service.cycle` 返回 `Step.LOCKED` 并在面板给出锁定提示。

1. **通用文本设置** (绘制设置cid=2):
   - 由 `system_setting_service.cycle` 在切换后遍历 `identity.table()`，自动更新全部角色的对应个人设置第 1 项
   - 全局同步角色文本使用偏好

2. **指令绘制数量与权重倍率** (绘制设置cid=11、14、15):
   - `system_setting_service.cycle` 分别返回 `Step.ASK_COUNT`（11 号）与 `Step.ASK_RATE`（14、15 号），面板据此弹出输入框读取数字
   - `system_setting_service.set_draw_number` 自动约束输入范围并写入 `draw_setting`（11 号存 `number - 1` 限 0~9，14、15 号限 1~99）

3. **禁止干员列表** (基础设置cid=7):
   - `option_rows` 在基础设置 7 号非零时置 `ban_list=True`，面板据此提供专门的干员选择界面入口
   - `system_setting_service.ban_rows` 组装非玩家角色列表，`system_setting_service.toggle_ban` 负责动态添加或移除禁止干员
   - 禁止已招募干员时，`toggle_ban` 直接调用 `roster_lifecycle_service.chara_off_line` 执行离岛逻辑

4. **生殖方式开关** (基础设置cid=13，plan_21):
   - `system_setting_service.CONTROLS` 将 `(Kind.BASE, 13)` 映射为 `Control.BIRTH_TYPE`，该行本身不是可切换选项（`option` 为单值），面板 `draw_option_row` 仅绘制 `[修改生殖方式开关]` 按钮跳转到子面板 `birth_type_setting_panel_draw`
   - 三个开关的数据是 CSV 中 `type=birth` 的独立分类（cid 直接取生育方式编号 2 多胎胎生、11 带壳卵生、12 无壳卵生），装载进 `config_birth_type_setting`，运行时值存在全局键 `save.settings` 的 `birth_type` 表中，由服务通过 `playthrough.settings(playthrough.BIRTH_TYPE)` 读、`playthrough.set_setting(playthrough.BIRTH_TYPE, 生育方式, 值)` 写
   - 由开启切换为关闭时先经面板 `confirm_close_birth_type` 二次确认，确认后调用 `system_setting_service.close_birth_type` 写入关闭并经 `egg_handle.clear_birth_type_data()` 立即清除存量数据且返回汇报文本，该操作不可撤销。由关闭切换为开启时直接调用 `system_setting_service.open_birth_type` 生效
   - 被关闭的生育方式在 `egg_handle.get_birth_type()` 处统一返回单胎胎生，详见[妊娠系统](妊娠系统.md)§2

### 5. 数据持久化

#### 存档系统集成
- **文件路径**: `Script/Core/save_handle.py`
- **处理逻辑**:
  - 在存档加载时检查设置完整性
  - 自动补充缺失的新设置项
  - 保持向前兼容性

#### 版本兼容性处理
```python
# 检查并补充缺失的基础设置
_live = attr_calculation.get_system_setting_zero()  # 以默认值为底（save_load.settings.install）
_apply(_live, data)  # 盖上 settings.json 里有的项，缺的新设置项保留默认值
```

## 数据流程图

```
CSV数据源 → buildconfig.py构建 → config_def.py定义
    ↓
game_config.py加载 → normal_config.system_setting运行时存储
    ↓
system_setting.py界面展示与用户交互 ↔ system_setting_service.py逻辑处理
    ↓
save_load.settings写进游戏根目录的settings.json（不随存档）
```

## 设置类型详解

### 基础设置 (base)
- **ID范围**: 1-8
- **主要功能**:
  - 能力自动升级控制
  - 射精位置选择模式
  - 精液流通功能开关
  - 干员禁止功能
  - 自动精液灌肠

### 难度设置 (difficulty)
- **ID范围**: 101-112
- **主要功能**:
  - 攻略难易度修正
  - 部位敏感度调整
  - 心智强韧度设置
  - 尿意值增长控制

### 绘制设置 (draw)
- **ID范围**: 201-211
- **主要功能**:
  - 界面布局控制
  - 信息显示详细度
  - 文本使用偏好
  - 数据显示开关

### 生殖方式设置 (birth)
- **ID范围**: 直接取生育方式编号（2多胎胎生、11带壳卵生、12无壳卵生）
- **特点**: 不在系统设置主列表中显示，由基础设置cid=13的入口按钮跳转到子面板修改
- **主要功能**: 分别关闭某种生殖方式，被关闭的生育方式所属种族一律按单胎胎生处理

## 扩展机制

### 添加新设置项
1. 在`System_Setting.csv`中添加新行
2. 运行`buildconfig.py`重新构建配置
3. 在相应的处理逻辑中添加特殊处理代码
4. 更新存档兼容性检查

### 自定义处理逻辑
系统支持为特定设置项添加自定义处理逻辑，如:
- 输入验证
- 级联更新
- 特殊界面展示
- 关联功能触发

## 使用示例

```python
from Script.Modules.gameplay_resolution import difficulty_service

# 获取当前难度系数
difficulty_level = playthrough.settings(playthrough.DIFFICULTY)[2]  # 难度随存档，在全局键 save.settings 中
coefficient = difficulty_service.get_difficulty_coefficient(difficulty_level)

# 检查是否开启自动升级
auto_upgrade = normal_config.system_setting.base_setting[1]

# 修改绘制设置
normal_config.system_setting.draw_setting[201] = 2  # 设置空行数量为3行
```

## 注意事项

1. **线程安全**: 设置修改直接操作缓存数据，需注意并发访问
2. **即时生效**: 大部分设置修改后立即生效，无需重启
3. **存档兼容**: 新增设置项需要在存档加载时进行兼容性处理
4. **界面同步**: 某些设置修改会触发界面元素的级联更新
5. **数据验证**: 特殊设置项需要进行输入值的有效性验证
