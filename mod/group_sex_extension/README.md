# 群交功能扩展

## 功能

- 在群交模式的“技艺”类别中增加“全员寸止”。
- 在群交模式的“技艺”类别中增加“全员戴上玩具”。
- 在群交模式的“技艺”类别中增加“全员催眠增强”。

## 全员催眠增强资格

“全员催眠增强”的可见性和执行目标都按完全催眠资格统计：角色拥有素质 `73`，或 `hypnosis_degree >= 200`。当前 `unconscious_h` 是否处于催眠激活态不参与资格过滤。

该指令只设置 `increase_body_sensitivity` 与 `pain_as_pleasure`，不会激活、切换或清空当前催眠态。非激活催眠态角色可以预先获得强化开关，实际结算是否生效仍由普通催眠态门控决定。

## 参与者来源

群交参与者同时来自群交模板和当前场景内 H 状态角色。先进入单人 H 的角色与后续通过直接邀请加入的角色使用同一套完全催眠资格规则。
